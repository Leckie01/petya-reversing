**출판사**: 인사이트

**난이도**: 초급~중급

### 초급 (1-3개월)

```
1. 기초 다지기
   - 책: 리버싱 핵심원리
   - 강의: Cybrary Malware Analysis
   - 실습: Crackmes.one (쉬운 문제)

2. 도구 익히기
   - Ghidra 튜토리얼
   - x64dbg 기본 사용법
   - PEStudio로 파일 분석
```

### 중급 (3-6개월)

```
1. 심화 학습
   - 책: Practical Malware Analysis
   - 강의: OpenSecurityTraining
   - 실습: RingZer0 CTF

2. 실전 분석
   - Petya 분석 가이드 실습
   - VirusTotal 샘플 분석
   - 분석 보고서 작성
```

```
1. 전문화
   - 책: The IDA Pro Book

2. 연구 및 기여
```
